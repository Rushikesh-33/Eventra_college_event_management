# Eventra — College Event Management System

A responsive college event management platform built with **HTML, CSS, and JavaScript**, designed to streamline event discovery, registration, approvals, attendance, and campus engagement.

## 📌 Overview

Eventra is a college-focused event management system that provides different dashboards and workflows based on user roles.

The platform supports students, event coordinators, faculty members, administrators, and guests, allowing different users to interact with events according to their responsibilities.

The current version is a frontend prototype using in-memory demo data.

---

## ✨ Features

### 🎓 Student

- Browse upcoming college events
- Search and filter events
- Register for events
- View registered events
- Access event tickets with QR codes
- View certificates
- Track points and leaderboard rankings
- View notifications
- Explore clubs and events
- Use the Eventra support chatbot

### 📋 Coordinator

- Create new events
- Submit events for faculty approval
- Manage created events
- Post live event updates
- Manage event attendance
- Generate/export attendance information
- Display event check-in QR codes

### 👨‍🏫 Faculty

- Review pending event submissions
- Approve or reject events
- Monitor approved events
- View event activity and analytics

### 🛠️ Administrator

- Manage users
- View and manage all events
- Manage clubs and societies
- Access reports and analytics
- View system activity logs

### 👤 Guest

- Browse invited events
- Explore available event information
